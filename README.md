# Crypters-Python

Overview
- Python utilities for encryption/"crypters".

Highlights
- Python-first crypto helpers (wrappers for common algorithms)
- Emphasis on simplicity and reuse

Quickstart
- Python 3.10+
- Suggested:
  - `python -m venv .venv`
  - `.venv\Scripts\activate`
  - `pip install -r requirements.txt` (if present)
  - `python <entry_script>.py`

Notes
- Document supported algorithms, key management, and example usage.
